# Project engineering skills

This directory contains the project's pinned copy of Addy Osmani's
[agent-skills](https://github.com/addyosmani/agent-skills).
Start with [the integration guide](../docs/agent-skills.md) and the root
[development instructions](../AGENTS.md).

The 25 skills in `skills/`, seven shared checklists in `references/`, supporting
skill files and [MIT notice](AGENT_SKILLS_LICENSE) are unchanged upstream bytes.
[agent-skills.lock.json](agent-skills.lock.json) records the exact source commit
and SHA-256 for every imported file. Run `npm run skills:verify` offline.
