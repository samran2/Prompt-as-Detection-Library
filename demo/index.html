      About the library

      An independently rebuilt prompt library covering every active Enterprise, Mobile, and ICS technique and sub-technique in the pinned MITRE ATT&CK 19.2 release. Revoked and deprecated records are excluded.

      The original v0.2.0 application source remains unavailable. This workbench is an independent implementation. Every prompt is an unvalidated draft; no model is called and no detection is certified or executed.

      Search, composition, edits, and downloads run in your browser. Context and drafts stay in this tab’s memory and clear on reload. The app sends no context. A hosting provider receives ordinary page requests. Source links open only when selected.

      Filtered JSONL includes all matching records across pages as freshly generated templates. Use Download .txt to save the current editor text, including your edits.
