                About the library

                An independently rebuilt prompt library covering 918 active Enterprise, Mobile, and ICS/OT records in MITRE ATT&CK 19.2, plus 197 AI techniques and subtechniques in MITRE ATLAS 2026.08. ATT&CK excludes revoked and deprecated records; ATLAS includes every technique record present in its pinned release.

                The original v0.2.0 application source remains unavailable. This workbench is an independent implementation. Every prompt is an unvalidated draft unless its record explicitly displays stronger review evidence; no model is called and no detection is certified or executed. ATLAS source threat maturity is not evidence of prompt validation.

                Search, composition, comparison, edits, and downloads run in your browser. Context and drafts stay in memory by default. Export a workspace file to keep them, or explicitly enable unencrypted local autosave. Browser storage can be cleared from Workspaces; downloaded files remain yours to manage. Search, filters, mode, target, selection, comparison and appearance are represented in or restored from the page URL; appearance is also remembered locally when storage is available. Workspace names, drafts, collections and context are never added to shared links. The app sends no analyst context. A hosting provider receives ordinary page requests. Source links open only when selected.

                Filtered JSONL includes all matching records across pages as freshly generated templates. Research JSON adds source relationships and explicit validation state. Use Download .txt to save the current editor text, including your edits.
