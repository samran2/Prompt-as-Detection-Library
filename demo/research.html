    05 · ATT&CK VERSION COMPARISON

    Review change before upgrading.

    Compare a proposed STIX bundle against the full pinned domain source using the local repository command. The report lists source changes and affected prompts. It never replaces ATT&CK 19.2 automatically.

    node scripts/attack_diff.cjs --domain Enterprise --candidate /path/to/proposed-bundle.json

    Runs locally from your repository checkout; nothing is uploaded. Use Mobile or ICS for those domain bundles.
