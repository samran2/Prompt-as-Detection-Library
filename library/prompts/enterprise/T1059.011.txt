Output target: Platform-neutral. This is an output instruction, not a verified integration.
Prompt profile: PAD-v0.4.0-dev3 (clear-task-focused-v3)

Behavior to investigate: Adversaries may abuse Lua commands and scripts for execution. Lua is a cross-platform scripting and programming language primarily designed for embedded use in applications. Lua can be executed on the command-line (through the stand-alone lua interpreter), via scripts (<code>.lua</code>), or from Lua-embedded programs (through the <code>struct lua_State</code>).(Citation: Lua main page)(Citation: Lua state)

Lua scripts may be executed by adversaries for malicious purposes. Adversaries may incorporate, abuse, or replace existing Lua interpreters to allow for malicious Lua command execution at runtime.(Citation: PoetRat Lua)(Citation: Lua Proofpoint Sunseed)(Citation: Cyphort EvilBunny)(Citation: Kaspersky Lua)
Suggested telemetry (confirm availability): WinEventLog:Sysmon; channel: EventCode=1; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; auditd:SYSCALL; channel: execve; data component: Process Creation; auditd:SYSCALL; channel: PATH; data component: File Metadata; macos:unifiedlog; channel: log stream; data component: Command Execution; networkdevice:runtime; channel: runtime; data component: Script Execution.
