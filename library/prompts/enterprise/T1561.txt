T1561 — Disk Wipe | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1561
Source tactics: Impact
Technique platforms: Linux, macOS, Windows, Network Devices

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.
Prompt profile: PAD-v0.4.0-dev3 (clear-task-focused-v3)

Behavior to investigate: Adversaries may wipe or corrupt raw disk data on specific systems or in large numbers in a network to interrupt availability to system and network resources. With direct write access to a disk, adversaries may attempt to overwrite portions of disk data. Adversaries may opt to wipe arbitrary portions of disk data and/or wipe disk structures like the master boot record (MBR). A complete wipe of all disk sectors may be attempted.

To maximize impact on the target organization in operations where network-wide availability interruption is the goal, malware used for wiping disks may have worm-like features to propagate across a network by leveraging additional techniques like [Valid Accounts](https://attack.mitre.org/techniques/T1078), [OS Credential Dumping](https://attack.mitre.org/techniques/T1003), and [SMB/Windows Admin Shares](https://attack.mitre.org/techniques/T1021/002).(Citation: Novetta Blockbuster Destructive Malware)

On network devices, adversaries may wipe configuration files and other data from the device using [Network Device CLI](https://attack.mitre.org/techniques/T1059/008) commands such as `erase`.(Citation: erase_cmd_cisco)
Suggested telemetry (confirm availability): WinEventLog:Security; channel: EventCode=4673; data component: User Account Metadata; WinEventLog:Sysmon; channel: Raw disk write access via \\.\PhysicalDrive* or \\.\C:; data component: Drive Modification; WinEventLog:Sysmon; channel: EventCode=6; data component: Driver Load; auditd:SYSCALL; channel: open/write syscalls on /dev/sd* or /dev/nvme*; data component: Drive Access; auditd:EXECVE; channel: Execution of dd, shred, wipe targeting block devices; data component: Process Creation; macos:unifiedlog; channel: diskutil eraseDisk / asr restore with destructive flags; data component: Command Execution; macos:unifiedlog; channel: IOKit disk write calls targeting raw devices; data component: Drive Modification; networkdevice:cli; channel: erase flash:, erase startup-config, format disk; data component: Command Execution; networkdevice:syslog; channel: User privilege escalation to level 15/root prior to destructive commands; data component: User Account Authentication.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
