T1137.003 — Outlook Forms | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1137/003
Source tactics: Persistence
Technique platforms: Windows, Office Suite
Parent technique: T1137 — Office Application Startup

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may abuse Microsoft Outlook forms to obtain persistence on a compromised system. Outlook forms are used as templates for presentation and functionality in Outlook messages. Custom Outlook forms can be created that will execute code when a specifically crafted email is sent by an adversary utilizing the same custom Outlook form.(Citation: SensePost Outlook Forms)

Once malicious forms have been added to the user’s mailbox, they will be loaded when Outlook is started. Malicious forms will execute when an adversary sends a specifically crafted email to the user.(Citation: SensePost Outlook Forms)
Suggested telemetry (confirm availability): WinEventLog:Sysmon; channel: EventCode=1; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=7; data component: Module Load; WinEventLog:Application; channel: Outlook errors loading or processing custom form templates; data component: Application Log Content; WinEventLog:PowerShell; channel: Execution of Microsoft script to enumerate custom forms in Outlook mailbox; data component: Command Execution; m365:unified; channel: Unusual form activity within Outlook client, including load of non-default forms; data component: Application Log Content; m365:messagetrace; channel: Inbound email triggers execution of mailbox-stored custom form; data component: Command Execution.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
