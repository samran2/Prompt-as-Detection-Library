T1027.005 — Indicator Removal from Tools | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1027/005
Source tactics: Stealth
Technique platforms: Linux, macOS, Windows

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may remove indicators from tools if they believe their malicious tool was detected, quarantined, or otherwise curtailed. They can modify the tool by removing the indicator and using the updated version that is no longer detected by the target's defensive systems or subsequent targets that may use similar systems.

A good example of this is when malware is detected with a file signature and quarantined by anti-virus software. An adversary who can determine that the malware was quarantined because of its file signature may modify the file to explicitly avoid that signature, and then re-use the malware.
