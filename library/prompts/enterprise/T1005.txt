T1005 — Data from Local System | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1005
Source tactics: Collection
Technique platforms: ESXi, Linux, macOS, Network Devices, Windows

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may search local system sources, such as file systems, configuration files, local databases, virtual machine files, or process memory, to find files of interest and sensitive data prior to Exfiltration.

Adversaries may do this using a [Command and Scripting Interpreter](https://attack.mitre.org/techniques/T1059), such as [cmd](https://attack.mitre.org/software/S0106) as well as a [Network Device CLI](https://attack.mitre.org/techniques/T1059/008), which have functionality to interact with the file system to gather information.(Citation: show_run_config_cmd_cisco) Adversaries may also use [Automated Collection](https://attack.mitre.org/techniques/T1119) on the local system.

Suggested telemetry (confirm availability): WinEventLog:Security; channel: EventCode=4688; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; auditd:SYSCALL; channel: open; data component: File Access; auditd:SYSCALL; channel: execve; data component: Process Creation; macos:unifiedlog; channel: process:spawn; data component: Process Creation; fs:fsusage; channel: read/write; data component: File Access; networkdevice:cli; channel: command logging; data component: Command Execution; esxis:vmkernel; channel: Datastore Access; data component: File Access; esxi:hostd; channel: Command Execution; data component: Command Execution.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
