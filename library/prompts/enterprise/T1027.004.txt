T1027.004 — Compile After Delivery | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1027/004
Source tactics: Stealth
Technique platforms: Linux, macOS, Windows

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may attempt to make payloads difficult to discover and analyze by delivering files to victims as uncompiled code. Text-based source code files may subvert analysis and scrutiny from protections targeting executables/binaries. These payloads will need to be compiled before execution; typically via native utilities such as ilasm.exe(Citation: ATTACK IQ), csc.exe, or GCC/MinGW.(Citation: ClearSky MuddyWater Nov 2018)

Source code payloads may also be encrypted, encoded, and/or embedded within other files, such as those delivered as a [Phishing](https://attack.mitre.org/techniques/T1566). Payloads may also be delivered in formats unrecognizable and inherently benign to the native OS (ex: EXEs on macOS/Linux) before later being (re)compiled into a proper executable binary with a bundled compiler and execution framework.(Citation: TrendMicro WindowsAppMac)
Suggested telemetry (confirm availability): WinEventLog:Sysmon; channel: EventCode=1; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; WinEventLog:Sysmon; channel: EventCode=3, 22; data component: Network Connection Creation; auditd:SYSCALL; channel: execve; data component: Process Creation; auditd:SYSCALL; channel: open,create; data component: File Creation; NSM:Flow; channel: conn.log; data component: Network Connection Creation; macos:unifiedlog; channel: process activity, exec events; data component: Process Creation; macos:osquery; channel: file_events; data component: File Creation; macos:unifiedlog; channel: networkd or socket; data component: Network Connection Creation.
