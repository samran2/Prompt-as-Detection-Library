Source tactics: Discovery
Technique platforms: ESXi, IaaS, Linux, macOS, Windows

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may attempt to get a listing of software and software versions that are installed on a system or in a cloud environment. Adversaries may use the information from [Software Discovery](https://attack.mitre.org/techniques/T1518) during automated discovery to shape follow-on behaviors, including whether or not the adversary fully infects the target and/or attempts specific actions.

Such software may be deployed widely across the environment for configuration management or security reasons, such as [Software Deployment Tools](https://attack.mitre.org/techniques/T1072), and may allow adversaries broad access to infect devices or move laterally.

Adversaries may attempt to enumerate software for a variety of reasons, such as figuring out what security measures are present or if the compromised system has a version of software that is vulnerable to [Exploitation for Privilege Escalation](https://attack.mitre.org/techniques/T1068).
Suggested telemetry (confirm availability): WinEventLog:Security; channel: EventCode=4688; data component: Process Creation; WinEventLog:PowerShell; channel: Execution of 'Get-WmiObject Win32_Product' or similar PowerShell cmdlets; data component: Command Execution; auditd:SYSCALL; channel: Execution of dpkg, rpm, or other package manager with list flag; data component: Process Creation; linux:shell; channel: Manual invocation of software enumeration commands via interactive shell; data component: Command Execution; macos:unifiedlog; channel: Execution of system_profiler or osascript invoking enumeration; data component: Process Creation; auditd:SYSCALL; channel: Command line arguments including SPApplicationsDataType; data component: Command Execution; AWS:CloudTrail; channel: ssm:ListInventoryEntries; data component: Cloud Service Enumeration; AWS:CloudTrail; channel: ssm:GetCommandInvocation; data component: Command Execution; esxi:shell; channel: esxcli software vib list; data component: Command Execution; esxi:hostd; channel: Host daemon command log entries related to vib enumeration; data component: Application Log Content.
