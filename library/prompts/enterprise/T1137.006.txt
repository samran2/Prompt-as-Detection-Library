T1137.006 — Add-ins | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1137/006
Source tactics: Persistence
Technique platforms: Windows, Office Suite

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may abuse Microsoft Office add-ins to obtain persistence on a compromised system. Office add-ins can be used to add functionality to Office programs. (Citation: Microsoft Office Add-ins) There are different types of add-ins that can be used by the various Office products; including Word/Excel add-in Libraries (WLL/XLL), VBA add-ins, Office Component Object Model (COM) add-ins, automation add-ins, VBA Editor (VBE), Visual Studio Tools for Office (VSTO) add-ins, and Outlook add-ins. (Citation: MRWLabs Office Persistence Add-ins)(Citation: FireEye Mail CDS 2018)

Add-ins can be used to obtain persistence because they can be set to execute code when an Office application starts. 
Suggested telemetry (confirm availability): WinEventLog:Sysmon; channel: EventCode=1; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; WinEventLog:Sysmon; channel: EventCode=2; data component: File Modification; WinEventLog:Sysmon; channel: EventCode=13, 14; data component: Windows Registry Key Modification; WinEventLog:Application; channel: Office Add-in load errors, abnormal loading context, or unsigned add-in warnings; data component: Application Log Content; WinEventLog:Microsoft-Office/OutlookAddinMonitor; channel: Outlook loading add-in via unexpected load path or non-default profile context; data component: Command Execution.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.

AN0137 — Analytic 0137
An adversary writes or drops a malicious Office Add-in (e.g., WLL, XLL, COM) to a trusted directory or modifies registry keys to load malicious add-ins on Office application launch. Upon user opening Word or Excel, the add-in is automatically loaded, triggering execution of the payload, often spawning scripting engines or anomalous child processes.
