T1217 — Browser Information Discovery | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1217
Source tactics: Discovery
Technique platforms: Linux, macOS, Windows

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may enumerate information about browsers to learn more about compromised environments. Data saved by browsers (such as bookmarks, accounts, and browsing history) may reveal a variety of personal information about users (e.g., banking sites, relationships/interests, social media, etc.) as well as details about internal network resources such as servers, tools/dashboards, or other related infrastructure.(Citation: Kaspersky Autofill)

Browser information may also highlight additional targets after an adversary has access to valid credentials, especially [Credentials In Files](https://attack.mitre.org/techniques/T1552/001) associated with logins cached by a browser.

Specific storage locations vary based on platform and/or application, but browser information is typically stored in local files and databases (e.g., `%APPDATA%/Google/Chrome`).(Citation: Chrome Roaming Profiles)
Suggested telemetry (confirm availability): WinEventLog:Sysmon; channel: EventCode=1; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; WinEventLog:PowerShell; channel: EventCode=4103, 4104, 4105, 4106; data component: Command Execution; auditd:SYSCALL; channel: open, read, or stat of browser config files; data component: File Access; linux:syslog; channel: Suspicious script or command execution targeting browser folders; data component: Command Execution; macos:unifiedlog; channel: Access to ~/Library/*/Safari or Chrome directories by non-browser processes; data component: File Access; macos:osquery; channel: process reading browser configuration paths; data component: Process Creation.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
