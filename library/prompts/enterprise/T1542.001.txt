Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may modify system firmware to persist on systems.The BIOS (Basic Input/Output System) and The Unified Extensible Firmware Interface (UEFI) or Extensible Firmware Interface (EFI) are examples of system firmware that operate as the software interface between the operating system and hardware of a computer.(Citation: Wikipedia BIOS)(Citation: Wikipedia UEFI)(Citation: About UEFI)

System firmware like BIOS and (U)EFI underly the functionality of a computer and may be modified by an adversary to perform or assist in malicious activity. Capabilities exist to overwrite the system firmware, which may give sophisticated adversaries a means to install malicious firmware updates as a means of persistence on a system that may be difficult to detect.
Suggested telemetry (confirm availability): WinEventLog:Security; channel: EventCode=4688; data component: Process Creation; WinEventLog:Sysmon; channel: EventCode=9; data component: Drive Access; WinEventLog:Sysmon; channel: EventCode=11; data component: File Creation; networkdevice:config; channel: Boot image path or firmware configuration variable modified outside of maintenance windows; data component: Firmware Modification; networkdevice:runtime; channel: Firmware image uploaded via TFTP/FTP/SCP; data component: Drive Modification.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
