T1674 — Input Injection | Enterprise | ATT&CK 19.2 reference
Source: https://attack.mitre.org/techniques/T1674
Source tactics: Execution
Technique platforms: Windows, macOS, Linux

Task: Propose detection logic, required telemetry, false positives, and bounded test cases.
Output target: Platform-neutral. This is an output instruction, not a verified integration.

Behavior to investigate: Adversaries may simulate keystrokes on a victim’s computer by various means to perform any type of action on behalf of the user, such as launching the command interpreter using keyboard shortcuts,  typing an inline script to be executed, or interacting directly with a GUI-based application.  These actions can be preprogrammed into adversary tooling or executed through physical devices such as Human Interface Devices (HIDs).

For example, adversaries have used tooling that monitors the Windows message loop to detect when a user visits bank-specific URLs. If detected, the tool then simulates keystrokes to open the developer console or select the address bar, pastes malicious JavaScript from the clipboard, and executes it - enabling manipulation of content within the browser, such as replacing bank account numbers during transactions.(Citation: BleepingComputer BackSwap)(Citation: welivesecurity BackSwap)

Adversaries have also used malicious USB devices to emulate keystrokes that launch PowerShell, leading to the download and execution of malware from adversary-controlled servers.(Citation: BleepingComputer USB)
Suggested telemetry (confirm availability): WinEventLog:System; channel: EventCode=2003; data component: Drive Creation; WinEventLog:Security; channel: EventCode=4688; data component: Process Creation; WinEventLog:PowerShell; channel: EventCode=4103, 4104, 4105, 4106; data component: Command Execution; auditd:SYSCALL; channel: execve: parent process is usb/hid device handler, child process bash/python invoked; data component: Process Creation; linux:syslog; channel: New HID device enumeration with type 'keyboard' followed by immediate input injection; data component: Drive Creation; macos:unifiedlog; channel: New IOUSB keyboard/HID device enumerated with suspicious attributes; data component: Drive Creation; macos:unifiedlog; channel: osascript, AppleScript, or Python execution triggered immediately after HID connection; data component: Script Execution.
