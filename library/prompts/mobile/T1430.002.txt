Output target: Platform-neutral. This is an output instruction, not a verified integration.
Prompt profile: PAD-v0.4.0-dev3 (clear-task-focused-v3)

Behavior to investigate: Adversaries may exploit the lack of authentication in signaling system network nodes to track the location of mobile devices by impersonating a node.(Citation: Engel-SS7)(Citation: Engel-SS7-2008)(Citation: 3GPP-Security)(Citation: Positive-SS7)(Citation: CSRIC5-WG10-FinalReport) 

 

By providing the victim’s MSISDN (phone number) and impersonating network internal nodes to query subscriber information from other nodes, adversaries may use data collected from each hop to eventually determine the device’s geographical cell area or nearest cell tower.(Citation: Engel-SS7)
Suggested telemetry (confirm availability): TelecomLogs:SS7Signaling; channel: Subscriber information queries, routing requests, or location update messages with anomalous node identifiers or unexpected origin patterns; data component: Network Traffic Content; TelecomLogs:MobilityEvents; channel: Unexpected location resolution events or abnormal subscriber tracking requests; data component: Network Traffic Flow; TelecomLogs:SS7Signaling; channel: Location resolution, routing, or subscriber information exchanges with anomalous signaling paths or node identities; data component: Network Traffic Content; TelecomLogs:MobilityEvents; channel: Unexpected subscriber tracking or abnormal mobility/location resolution activity; data component: Network Traffic Flow.
Benign activity to consider: Local-baseline guidance (not a source finding): establish approved activity, expected accounts, assets, schedules and change windows for this behavior. Review source tuning variables; require local evidence before making exclusions.
