# Model-evaluation evidence

No model run is recorded in this baseline.

`static/` contains deterministic source-parity and guardrail scorecards. Those
records are automated checks, not model evaluations or human reviews.

Future manifests must record the exact provider and model identifier, settings,
execution date, prompt SHA-256, response SHA-256, evaluator version and rubric
version. Store only content approved for public release. Credentials and private
environment context belong in the runner environment, never in this directory.
