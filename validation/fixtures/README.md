# Fixture contribution contract

No executable detection fixtures have been accepted yet.

For a supported native rule, contribute at least one inert fixture of each
class: `positive`, `benign-lookalike`, `missing-telemetry` and
`threshold-boundary`. A fixture manifest must identify its prompt and rule,
declare the expected outcome before execution, record a SHA-256 for the exact
input, and avoid real personal, customer or production data.
