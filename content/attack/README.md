# Pinned ATT&CK content boundary

ATT&CK 19.2 is the pinned content version for this development line. The
immutable source files, MITRE license, manifest, commit identity, and source
hashes remain in [`sources/attack-19.2/`](../../sources/attack-19.2/) during the
compatibility transition.

This directory reserves the stable content boundary for a future reviewed data
migration. It must not contain a second, independently editable copy of the
pinned source. ATT&CK upgrades arrive as proposal changes and require source,
license, diff, generation, and regression review before acceptance.
